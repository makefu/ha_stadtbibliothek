# Stuttgart (and Remseck) Stadtbibliothek Home-assistant Integration
[stadtbibliothek-stuttgart](https://stadtbibliothek-stuttgart.de/) home-assistant custom component. It provides a clear overview of all items loaned by different users (can be instanciated multiple times). An overview of all items can be shown. Based on the sensors, automations can be built to get warned: e.g. when the items cannot be lent further and when no extensions are possible.


## Installation
- [HACS](https://hacs.xyz)


## Integration
Currently there there are integrations planned for two libraries: `stuttgart` and `remseck`
