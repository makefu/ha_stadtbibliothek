Anleitungen

Sie müssen angemeldet sein. Sie vergeben einen Titel für Ihre Suchanfrage, die danach gespeichert wird. Ihre gespeicherten Suchanfragen können Sie von Ihrem Konto aus aufrufen.

Durch Anklicken einer Merkliste wird diese an die erste Position platziert und wird zur aktiven Merkliste. Ist das Stern-Icon gefüllt, führt der Klick auf diese aktive Merkliste zur Anzeige der Merkliste.

Klicken Sie einen Filter an, um dessen Werte anzuzeigen.
Sie können Ihre Trefferliste einschränken, indem Sie einen oder mehrere dieser Werte von einem oder mehrere(n) Filtern auswählen und auf die Schaltfläche "Filter" klicken. Sie können Ihre eingeschränkte Trefferliste wieder erweitern, indem Sie die Häkchen der Werte unter der Rubrik "Aktive Filter" wieder entfernen und die Schaltfläche "Filter" auslösen.

Die Vorsortierung ist nach Titel/Jahr eingestellt. Wenn Sie eine neue Sortierung wünschen, dann hängt dies von der zu sortierenden Treffermenge ab. Bei großen Treffermengen ist die Sortierung nicht möglich.

Sie können bis zu 300 Titel als Textdatei exportieren. Aufgrund der Größe dieser Datei bitten wir Sie um etwas Geduld, bis der Download zur Verfügung steht.
